# 图片查看器 denial_gallery — 设计规范

> 配套设计稿：`docs/designs/gallery-redesign.html`
> 状态：设计已确认，待实现
> 定位：Denial 平板原生图片查看器。网格浏览 + 沉浸式单图查看 + 基础编辑（裁剪/旋转）。

---

## 1. 目标与形态

一个插件 `denial_gallery`，窗口化应用（标题栏三段式，与 sysmon/appstore 一致）：

| 模式 | 说明 |
|---|---|
| **网格**（主窗口） | 左文件夹导航 + 右侧缩略图网格，按日期分组 |
| **查看**（全窗口） | 沉浸式单图 + 顶部信息 + 底部操作栏 |
| **编辑**（全窗口） | 裁剪框 + 旋转，完成时询问覆盖/另存 |

## 2. 数据源

| 来源 | 路径 |
|---|---|
| Linux 图片 | `~/Pictures`（含 `Screenshots/`）、`~/Downloads`、`~/Documents` |
| Android 图片 | `/sdcard/DCIM`、`/sdcard/Pictures`（droidloom 共享目录，与 Linux 侧互通） |

左栏的"Android 相机"入口指向 DCIM。目录扫描使用 inotify 监听，新增文件自动刷新。

## 3. 界面结构

### 3.1 网格页

- **左栏**：全部照片（计数）、最近添加、收藏；分隔线下按文件夹（Pictures / 屏幕截图 / 下载 / Android 相机）
- **标题栏**：搜索框、排序按钮、缩略图大小滑块（紧接 logo 右侧、靠左排列）
- **内容顶栏**：仅标题 + 数量
- **网格**：按日期分组（今天/昨天/具体日期），缩略图正方形裁剪、圆角 8px
  - 屏幕截图用文档样式预览；视频带时长角标
  - 选中态：accent 描边
- 点击缩略图进入查看；双击直接最大化查看

### 3.2 查看模式

- **左侧图片列表**（138px）：显示当前图片前后各若干张缩略图 + 文件名，当前项 accent 描边并居中可见；
  点击任一项即切换，列表随切换自动滚动
- **顶部栏**：返回、文件名、尺寸/大小/序号、信息（ⓘ）、更多（⋯）、窗口控制
- **舞台**：图片居中，圆角 6px，阴影；**切换图片的按钮移到底部栏**（不再悬浮在图片两侧）
- **底部栏**：`上一张` / 缩小 / 放大 / 缩放状态 / 旋转 / 裁剪 / 分享 / 删除 / `下一张`
- **信息面板**（ⓘ 切换）：文件名、尺寸、大小、拍摄时间、路径、EXIF、来源

### 3.3 编辑模式

- 裁剪：四角手柄 + 九宫格辅助线；比例 自由 / 1:1 / 16:9 / 4:3
- 旋转：左旋 90° / 右旋 90° / 重置
- 完成：弹窗选择「覆盖原图」或「另存为副本」（默认另存）

## 4. 交互规范

| 操作 | 行为 |
|---|---|
| 单击缩略图 | 进入查看模式 |
| 双击图片 | 在「适应窗口」与「100%」间切换 |
| 双指捏合 | 自由缩放（10%–800%） |
| 拖动 | 缩放 > 适应窗口时平移 |
| 底部「上一张 / 下一张」按钮 / 方向键 | 上一张 / 下一张（按当前文件夹顺序） |
| 点击左侧图片列表项 | 切换到该项；列表自动滚动跟随当前项 |
| Esc | 查看/编辑模式返回网格 |
| 空格 | 幻灯片开始/暂停（全屏轮播，5 秒/张） |
| 删除 | 确认后移到回收站（`~/.local/share/Trash`），不直接 unlink |

## 5. 格式与解码

- 静态：JPEG / PNG / WebP / AVIF / GIF / SVG / BMP / TIFF
- 原始：RAW 首期不支持（可后续接 libraw）
- 视频缩略图：ffmpeg 取首帧（已装）
- 动图（GIF/WebP）：查看模式播放，网格显示首帧
- 缩放采用区域解码（只解码视口内区域），避免 4032×3024 全图进内存

## 6. 性能

- 缩略图：256px 缓存到 `~/.cache/denial/gallery/`，按 mtime+size 作 key
- 网格滚动按需加载（视口 ± 2 屏）
- 大图查看使用渐进解码 + 分块，峰值内存目标 < 200MB
- 目录扫描异步，避免阻塞 UI

## 7. 竖版布局

| 元素 | 竖版变化 |
|---|---|
| 左栏 | 收进**顶部文件夹 chips**（横滚） |
| 网格 | 6 列 → **3 列** |
| 查看底部栏 | 隐藏文字副标签，只留图标 |
| 标题栏 | 窗口按钮减为最小化/关闭 |

## 8. 明确不做（YAGNI）

- 图像编辑进阶功能（滤镜、调色、去背、AI 修饰）
- RAW 解码
- 云同步/相册分享链接
- 人脸识别/智能分类
- 批量重命名（首期）

## 9. 验收标准

- [ ] 网格：Linux 与 Android 目录的图片同列，按日期分组正确
- [ ] 缩略图：屏幕截图文档预览、视频时长角标正确
- [ ] 排序/搜索/缩略图大小滑块生效
- [ ] 查看：缩放（捏合/双击/按钮）、平移、旋转、切换上一张/下一张正常
- [ ] 查看模式左侧图片列表：显示前后图片，当前项高亮，点击切换且列表自动滚动跟随
- [ ] 信息面板：尺寸/大小/路径/EXIF 与实际文件一致
- [ ] 裁剪：四角拖动、比例切换、旋转、完成时覆盖/另存
- [ ] 删除进回收站而非直接删除
- [ ] 大图（4032×3024）打开内存峰值 < 200MB，缩放流畅
- [ ] 竖版：chips + 3 列网格，查看模式图片区域最大化
- [ ] settings 改全局色调后 accent 跟随

## 10. 实现落点（参考）

| 层 | 位置 | 工作 |
|---|---|---|
| 扫描与索引 | `plugins/denial_gallery/core/` | inotify 目录监听、缩略图生成与缓存、EXIF 读取 |
| 解码 | 复用 image 解码（Flutter 引擎 / 或 Rust image crate） | 区域解码、渐进加载 |
| UI | `plugins/denial_gallery/lib/src/` | 网格 / 查看 / 编辑 / 信息面板 + 竖版 |
| 集成 | `plugins/denial_desktop` | 从文件管理器/appstore 用"打开方式"唤起 |
